Bolded rows are why this branch is the right base: the four libraries a CRM-backed client needs —
typed HTTP, server-state caching, OAuth PKCE, and Keychain-backed token storage — are already
installed and already wired in `src/lib/auth.ts`. Starting from `main` would mean adding all four.

`package.json` also pins 8 transitive `overrides` (xmldom, ajv, node-forge, tar, yaml, …), which came
from commit `18feb12 security: remove all hardcoded secrets and tokens`. Preserve them.

### Delta vs `main`

`main` has: expo ~55.0.5, RN 0.83.2, no react-query, no axios, no auth-session, no secure-store, no
svg, no EAS. `main`'s only data layer is `fetch` in `src/lib/api.ts`. `cms-integration` is strictly
ahead — it contains every commit on `main` plus 12 more.
